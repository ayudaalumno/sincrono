  <section class="card">

    <h2>Método 1: Gestores de credenciales nativos (Recomendado HTTPS)</h2>

    <p>El sistema operativo guarda el token o la sesión del navegador y no vuelve a pedir credenciales en cada <code>push</code> o <code>pull</code>.</p>


    <h3><span class="badge win">Windows</span> Git Credential Manager</h3>

    <ol>

      <li>Abre <strong>PowerShell</strong> o <strong>CMD</strong> y activa el gestor:

        <pre><code>git config --global credential.helper manager</code></pre>

      </li>

      <li>Al hacer tu próximo <code>git push</code>, se abrirá una ventana emergente en el navegador solicitando autorización. Confirma el inicio de sesión en tu cuenta de GitHub.</li>

    </ol>


    <h3><span class="badge mac">macOS</span> Llavero del sistema (Keychain)</h3>

    <ol>

      <li>Abre la <strong>Terminal</strong> y activa el llavero:

        <pre><code>git config --global credential.helper osxkeychain</code></pre>

      </li>

      <li>Al hacer el siguiente <code>git push</code>:

        <ul>

          <li><strong>Username:</strong> Tu usuario de GitHub</li>

          <li><strong>Password:</strong> Pega tu <em>Personal Access Token (PAT)</em></li>

        </ul>

      </li>

      <li>macOS guardará la clave en el llavero de forma indefinida.</li>

    </ol>

  </section>


  <!-- MÉTODO 2 -->

  <section class="card">

    <h2>Método 2: Autenticación por claves SSH (Sin tokens)</h2>

    <p>Permite vincular cada máquina de forma permanente mediante pares de claves pública/privada.</p>


    <h3><span class="badge mac">macOS</span> Configuración SSH</h3>

    <ol>

      <li>Genera el par de claves:

        <pre><code>ssh-keygen -t ed25519 -C "mac"</code></pre>

        <em>(Presiona Enter para aceptar la ruta por defecto y opcionalmente define una frase de paso).</em>

      </li>

      <li>Copia la clave pública al portapapeles:

        <pre><code>pbcopy &lt; ~/.ssh/id_ed25519.pub</code></pre>

      </li>

      <li>Entra a GitHub &gt; <strong>Settings</strong> &gt; <strong>SSH and GPG keys</strong> &gt; <strong>New SSH key</strong>. Pon de título <code>Mac</code> y pega el contenido.</li>

      <li>Cambia la URL del repositorio local al formato SSH:

        <pre><code>git remote set-url origin git@github.com:TU_USUARIO/TU_REPOSITORIO.git</code></pre>

      </li>

    </ol>


    <h3><span class="badge win">Windows</span> Configuración SSH</h3>

    <ol>

      <li>Genera el par de claves en <strong>PowerShell</strong>:

        <pre><code>ssh-keygen -t ed25519 -C "windows"</code></pre>

      </li>

      <li>Muestra y copia el contenido de la clave pública:

        <pre><code>Get-Content ~/.ssh/id_ed25519.pub</code></pre>

      </li>

      <li>En GitHub &gt; <strong>Settings</strong> &gt; <strong>SSH and GPG keys</strong> &gt; <strong>New SSH key</strong>, añade una nueva clave con título <code>Windows</code> y pega el texto.</li>

      <li>Cambia la URL de tu repositorio a SSH:

        <pre><code>git remote set-url origin git@github.com:TU_USUARIO/TU_REPOSITORIO.git</code></pre>

      </li>

    </ol>


    <div class="note">

      <strong>Comprobación rápida:</strong> Para verificar la conexión SSH en cualquier máquina ejecuta:

      <code>ssh -T git@github.com</code>. Deberías ver un mensaje de bienvenida de GitHub.

    </div>
